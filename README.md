## 腾讯云服务器流量包价格是多少？先确认你买的是哪一种

腾讯云目前有三种叫“流量包”的产品，价格体系和适用范围完全不同。

1. **共享流量包**：预付费，按月或按半年购买，抵扣公网网络计费模式为「按流量计费」的 CVM、EIP 等资源的出流量。这是大多数人搜“腾讯云服务器流量包价格”时真正要找的产品，也是唯一有稳定公开价目表的。
2. **轻量应用服务器套餐内流量包**：跟套餐绑定，不单独售卖，每个自然月重置，超出后按套餐外超额流量计费。

## 共享流量包的五条使用限制，会直接影响账单

共享流量包不是买了就自动变便宜，下面几条限制在计费文档里写着，但购买页不一定显眼。

1. **一个包只覆盖一个地域**。北京买的包不能抵扣广州的流量，也不能跨到香港。
2. **只抵扣「按流量计费」的资源**。如果你的 CVM 选的是包年包月带宽，或者已经加入了共享带宽包，流量包不参与抵扣。
3. **到期清零，不支持退还**。月包 1 个月、半年包 6 个月，没用完的流量直接作废，也不会退钱。
4. **不影响带宽峰值**。流量包只是流量额度，不会把你的 5Mbps 变成 50Mbps。
5. **统计的是出方向流量**，而且实际统计值会比你在服务器里看到的应用层流量多 10% 左右。TCP/IP 包头约占 3%，公网丢包后的 TCP 重传占 3%–7%，这两部分你在系统里统计不到，但会计费。

第 3 条最容易被忽略。如果不确定自己的月用量，先按小额规格买，或者干脆先按流量计费跑一个完整账期，看账单再决定。 👉 [按实际用量挑一个共享流量包规格](https://bit.ly/yunhuodong)

## 轻量应用服务器的流量怎么算

轻量应用服务器不用共享流量包，它的流量走套餐。套餐里包含的月流量包只统计出流量，以实例购买时间为起点，每个自然月重置一次，重置时间和计费周期一致。当月没用完的流量不退还，超出部分按「套餐外超额流量」计费，每小时结算。

欠费状态下，超出月流量包限额的实例在前 2 小时正常推量扣费，2 小时后进入停服状态；没有超额的实例不受影响。充值到余额大于 0，或者等流量包按月重置，实例就能恢复。

如果套餐内流量长期不够用，香港和新加坡地域的轻量实例可以考虑轻量优选流量包。它是独立售卖的预付费流量套餐，抵扣轻量应用服务器的流量消耗，卖点是中国香港、新加坡到中国大陆的线路质量比普通套餐流量更好。这类产品的价格跟活动走，下单前看活动页的实时标价。

## 几个下单前常问的问题

**流量包买完需要设置吗？**
不需要。购买完成后会自动抵扣公网网络计费模式为按流量计费的资源。

**共享流量包和共享带宽包是一回事吗？**
不是。共享流量包买的是流量额度，用完为止；共享带宽包是把多个 IP 的带宽聚合成一个计费池，加入带宽包后，资源的公网网络计费模式会变成共享带宽包模式，两者不能混用。

**流量包会限制带宽峰值吗？**
不会。带宽峰值由实例自身的带宽上限决定，流量包只影响流量费用的抵扣。

**多个流量包怎么抵扣？**
按流量包的地域和有效期分别抵扣，闲时包只在 0:00–8:00 生效，全时包全天生效。同时持有两种包时，闲时段的流量优先走闲时包。
